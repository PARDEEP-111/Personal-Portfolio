## Features

- **Responsive layout** — custom breakpoints for mobile, tablet, and desktop, built mobile-first with Tailwind CSS
- **Sticky navbar** with a frosted-glass (backdrop-blur) effect, animated hamburger menu on mobile, and smooth-scroll navigation to each section
- **Horizontal scroll carousels** (Tech Stack and Projects sections) with custom left/right controls, scroll-snap, and a shared reusable `useHorizontalScroll` hook
- **Animated interactions** — underline-on-hover nav links, icon cross-fade on the mobile menu button, staggered entrance animations (Framer Motion)
- **Data-driven sections** — Tech Stack, Projects, and Education & Experience are all rendered from arrays, making content easy to update
- **Contact section** styled as a code block (`contact.jsx`), reflecting my background as a developer

## Tech Stack

- React
- Tailwind CSS
- Vite
- Framer Motion
- Lucide React (icons)

## Sections

1. **Hero** — introduction, role, and call-to-action buttons (Get In Touch / Download Resume)
2. **Tech Stack** — scrollable list of tools and languages I work with
3. **Projects** — scrollable showcase of projects, each linking to a live demo or repo
4. **Education & Experience** — timeline of my education and work history
5. **Let's Connect** — contact details (email, phone, location, GitHub, LinkedIn)
6. **Footer**
